# 健身打卡 App

## 启用拍照估算热量

### 本机运行

1. 把 `.env.example` 复制为 `.env.local`，填入自己的 `DEEPSEEK_API_KEY`。本机运行时可以留空 `MEAL_ACCESS_CODE`。
2. 运行 `npm ci` 和 `npm run dev`，访问终端显示的本地地址。
3. 打开「饮食」，拍照或选择相册照片，点「用 DeepSeek 估算热量」。确认菜名、份量和热量后保存。

DeepSeek 密钥保存在服务端，浏览器不会拿到密钥。选择照片后可以先预览，只有点估算按钮才会发送照片。保存后，浏览器本地只保留饮食条目和热量。

### 网页版部署

现有 GitHub Pages 只能提供静态网页。要使用拍照识别，可在 Netlify 将本项目作为同一个站点构建和部署：

1. 使用包含饮食功能的 Git 分支。保留仓库现有的 `netlify.toml` 构建设置。
2. 在站点的 Functions 运行环境设置 `DEEPSEEK_API_KEY`，并配置仅给使用者的高强度随机 `MEAL_ACCESS_CODE`。
3. 部署后，在站点的「饮食」页使用照片识别。首次识别时按页面提示输入访问码，然后点估算。
4. 训练和饮食记录按网址、浏览器分别保存。换到新的站点地址后，新地址会从空白记录开始。

服务端没有配置时，仍可手动填写菜名和热量。
